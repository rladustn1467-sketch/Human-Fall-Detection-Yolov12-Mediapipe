# 낙상 예방 콘텐츠 작성 방법

웹앱의 **낙상 예방** 메뉴는 이 폴더의 JSON 파일을 읽어 그대로 보여 줍니다.
내용을 추가하거나 고칠 때는 **이 폴더의 파일만** 바꾸면 되고, 화면 코드(`js/screens/prevention.js`)는 고치지 않아도 됩니다.
파일을 저장한 뒤 브라우저를 새로 고치면 바로 반영됩니다 (서버 재시작 필요 없음).

## 파일

| 파일 | 내용 |
|---|---|
| `index.json` | 메뉴에 보일 영역의 **순서** (`areas` 에 파일 이름을 나열) |
| `exercise.json` | 낙상 예방 운동 |
| `home-check.json` | 가정 내 위험 요소 점검 |
| `daily-rules.json` | 일상생활 안전 수칙 |
| `resources.json` | 예방 정보와 자료 |

새 영역을 만들려면 `새이름.json` 파일을 만들고 `index.json` 의 `areas` 에 `"새이름"` 을 추가하세요.
파일 이름(id)은 **영문 소문자, 숫자, `-`** 만 쓸 수 있습니다.

## 영역 파일 형식

```json
{
  "id": "exercise",
  "title": "낙상 예방 운동",
  "summary": "목록과 상세 화면 위쪽에 보이는 한두 문장",
  "status": "draft",
  "sections": [
    {
      "heading": "소제목",
      "paragraphs": ["문단 1", "문단 2"],
      "items": ["목록 항목 1", "목록 항목 2"]
    }
  ]
}
```

- `status`: `"draft"`(준비 중으로 표시) 또는 `"published"`(내용 표시). `published` 이면서 `sections` 가 1개 이상일 때만 내용이 보입니다.
- `heading`, `paragraphs`, `items` 는 모두 선택입니다. **글자만** 쓸 수 있고 HTML 태그는 그대로 글자로 보입니다.
- JSON 은 마지막 항목 뒤에 쉼표를 쓰면 오류가 납니다. 저장 전에 형식을 확인하세요.

## 주의

- 의학적 내용(운동 방법, 횟수, 지침 등)은 근거 자료를 확인한 뒤 넣어 주세요. 출처는 `resources.json` 등에 함께 적는 것을 권장합니다.
- 이 폴더의 파일은 로그인한 사용자에게만 제공됩니다 (`/app/content/...`).
